# zen.fedora.makemkv.Install
This script will install MakeMKV to Fedora Workstation OS.

## Notes
> The script includes all pre-requisites necessary to get MakeMKV up and running.
>
> The version of MakeMKV that will be installed is 1.17.7
>
> Update the software at your own risk.
>
> DO NOT UPDATE MAKEMKV if you have a blu-ray drive. All later versions have an issue where they will say "scanning drives" indefinitely.
>
> This script should in theory also work for Rocky, RHEL, and CentOS operating systems.
